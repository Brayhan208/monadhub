# MonadHub 🚀
> Gobernanza Descentralizada, Votaciones On-Chain y Crowdfunding en Monad Testnet.

## 📌 Descripción General
MonadHub es una plataforma descentralizada diseñada para facilitar la toma de decisiones comunitarias transparentes, el financiamiento participativo y la acreditación Web3, aprovechando la velocidad y bajas comisiones de la red **Monad Testnet**.

## ✨ Características Principales
- 🗳️ **Votaciones On-Chain e Inmutables:** Creación de encuestas con URL/Slug únicos y firma de votos mediante MetaMask (EIP-191).
- 🐄 **La Vaca (Crowdfunding):** Recaudación de fondos en tiempo real con aportes directos en MON.
- 🎓 **Certificados Acreditados:** Emisión y verificación de credenciales digitales registradas en la blockchain.
- ⚡ **Rendimiento:** Interfaz optimizada en tiempo real mediante Supabase Cloud y contratos inteligentes en Solidity.

## 🛠️ Stack Tecnológico
- **Frontend:** Vanilla HTML5 / CSS3 / JavaScript
- **Web3 Integración:** Ethers.js v5
- **Smart Contract:** Solidity `0.8.20` (`MonadHubGovernance.sol`)
- **Blockchain:** Monad Testnet (Chain ID `10143`)
- **Base de Datos & Auth:** Supabase Cloud
- **Hosting:** Vercel
